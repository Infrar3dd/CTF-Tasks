# fooled

### Stego

### Description

Недавно написал одному админу канала по хакингу, попросил скинуть ссылки на его полезные ресурсы, он ответил, что скинет, а в итоге обманул, поможешь? :[

формат: indhell{...}
(файл fooled.pdf)

---
### Solution

Изображения не были изменены через редактор изображений, а поверх них просто наложена фигура => из .pdf можно вытащить исходные фотографии, например с помощью утилиты pdfimages
```bash
pdfimages -all fooled.pdf image
```
На изображениях даны ссылки на Standoff365 автора, ложная ссылка и ссылка на Pastebin.

На Pastebin находим флаг: xcswtaa{h!beat_g!vwi?}

Дешифруем ROT13 на 11 символов
